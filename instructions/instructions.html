Инструкция по получению credentials.json

1. Создайте проект в Google Cloud Console

  1. Перейдите на Google Cloud Console
  2. Нажмите "Create Project"
  3. Назовите проект "WhatsApp Reminder"

2. Включите Google Calendar API

  1. В меню слева выберите "APIs & Services" → "Library"
  2. В поиске найдите "Google Calendar API"
  3. Нажмите "Enable" (Включить)

3. Создайте учетные данные

  1. Перейдите в "APIs & Services" → "Credentials"
  2. Нажмите "Create Credentials" → "OAuth Client ID"
  3. Выберите "Desktop application"
  4. Введите название: "WhatsApp Reminder"

4. Скачайте и настройте файл

  1. Скачайте JSON-файл (иконка скачивания)
  2. Переименуйте файл в credentials.json
  3. Положите файл в папку с программой

5. Добавьте себя в тестовые пользователи

  1. В "APIs & Services" → "OAuth consent screen"
  2. В разделе "Test users" добавьте ваш email
  3. Сохраните изменения

Готово! Теперь можно запускать программу.
