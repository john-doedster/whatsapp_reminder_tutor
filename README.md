# WhatsApp Reminder для Репетиторов

🚀 Автоматизация отправки напоминаний ученикам через WhatsApp

## Возможности

- 📅 Интеграция с Google Календарем
- 📞 Автоматическая отправка напоминаний в WhatsApp
- 👥 Удобное управление контактами учеников
- 🎯 Простой графический интерфейс

## Установка

1. Скачайте последнюю версию из [Releases](#)
2. Запустите `install.bat`
3. Настройте `credentials.json` для Google API
4. Запустите `start.bat`
