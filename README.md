# WhatsApp Reminder для Репетиторов v1.0

🚀 Автоматизация отправки напоминаний ученикам через WhatsApp

## Возможности версии 1.0

- 📅 Интеграция с Google Календарем
- 📞 Автоматическая отправка напоминаний в WhatsApp
- 👥 Удобное управление контактами учеников через GUI
- 🎯 Простой графический интерфейс
- 📊 Лог выполнения операций

## Установка

1. Скачайте `whatsapp-reminder-v1.0.zip` из раздела Releases
2. Распакуйте архив
3. Запустите `install.bat` для установки зависимостей
4. Настройте `credentials.json` для Google API
5. Запустите `start.bat` для работы приложения
